# TaskFlow

TaskFlow es una aplicación móvil desarrollada con React Native y Expo para organizar y gestionar tareas. Este proyecto forma parte de una entrega para CoderHouse y utiliza Expo Router para la navegación.

## Ejecutar el proyecto localmente

1. Clona el repositorio y abre una terminal en la carpeta del proyecto.

2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo de Expo:

   ```bash
   npx expo start
   ```

4. Sigue las opciones que aparecen en la terminal para abrir la aplicación en Expo Go, un emulador de Android, un simulador de iOS o el navegador web.

## Tecnologías

- React Native
- Expo SDK 54
- Expo Router
- TypeScript
